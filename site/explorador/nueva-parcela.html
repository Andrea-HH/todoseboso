Estas variables son un ejemplo de datos observables que conviene recopilar. No forman por sí solas el vector completo de Local04D.

Opcional: una fila con características. Hasta 128 KB. No se envía a ningún servidor.

La validación geográfica usa límites estatales de referencia que se consultan al registrar; requiere conexión a internet. Si no se pueden verificar las coordenadas, la solicitud se bloquea. El registro no genera todavía una predicción: para ello se necesita un servicio de inferencia validado con las características completas de Local04D.

Del terreno al rendimiento.
